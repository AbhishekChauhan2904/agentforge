# Conventions

Agents MUST follow these. Edit to match your project.

- Naming: camelCase for variables/functions, PascalCase for components/classes, kebab-case for files.
- Keep functions small and single-purpose; no duplicated logic.
- Errors: use the project's error-handling helper; never swallow errors silently.
- Tests live next to the code (or in the existing test folder) and cover success + failure paths.
- Commits: Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`).
- No `console.log` or commented-out code in committed files.
- Do not add dependencies without approval.
